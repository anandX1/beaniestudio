# Master prompt — paste this to start any new Claude session on the site

```
You're working on beaniestudio.site, the official website for STATIC, a free co-op
asymmetrical horror game on Roblox by Beanie Studios (team: Anand Kumar — scripting;
Pawan Dahe — map/community; Jai Mishra — content/audio). Repo: anandX1/beaniestudio.

READ THESE FIRST, IN ORDER, BEFORE CHANGING ANYTHING:
1. site/CLAUDE.md          — design contract + rules (facts, tokens, motion, SEO hygiene)
2. site/src/data/game.ts   — the ONLY source of game facts/numbers. Never invent mechanics.
3. site/SEO-PLAYBOOK.md    — researched SEO/reach strategy and what's already done
4. site/MEDIA-WISHLIST.md  — media plan (videos/clips) and how they're used
5. site/LAUNCH-PACK.md     — launch copy, outreach templates, devlog briefs
6. README.md               — deploy model

HOW THE SITE WORKS
- Astro 5 + Tailwind v4 source in site/. The repo ROOT is the built site; Cloudflare
  Workers (static assets) deploys main automatically on push. .assetsignore keeps .git,
  site/, game-assets/ out of the upload (a .git pack >25 MiB once broke every deploy).
- Workflow: cd site → npm ci → (npm run media if screenshots changed) → npm run check →
  npm run build → npm run check:links → npm run sync-root → commit → push to main.
- Screenshots: raw in game-assets/, registered in site/src/data/media.json, generated by
  scripts/media.mjs to public/media/*.webp. Render with Shot.astro / ShotFigure.astro.
- Motion is CSS scroll/view timelines only (no GSAP), behind @supports and
  prefers-reduced-motion. Keep Lighthouse ≥95 on every category.
- CI (.github/workflows/seo.yml) builds, runs Lighthouse, audits the LIVE site
  (titles ≤60 chars incl. &amp;, descriptions ≤165), pings IndexNow.

HARD RULES
- Facts only from game.ts. If I tell you new facts, update game.ts first.
- No AI-mass-generated blog posts (autopilot stays paused). Devlogs come from the team's
  real stories.
- No buying links, no keyword stuffing, no hidden text, no fake reviews/numbers.
- Emails: hello@, press@, anand@, pawan@, jai@ @beaniestudio.site only.
- Verify with screenshots (Playwright, desktop 1440 + phone 390) and Lighthouse before
  pushing. After pushing, check the CI run's live audit passed.

TODAY'S TASK:
[describe what you want — e.g. "add these 12 videos from game-assets/videos/ as loops and
build /videos/ watch pages with VideoObject markup", "add launch codes ABC and XYZ to the
codes page", "write a devlog from these notes: …", "patch notes for update 1.1: …"]
```

- "Read Search Console export (attached) and tell me which pages to improve and how."
- "Update game.ts for update X: [changes]. Then fix every page that mentions it."
- "Build /videos/ watch pages for these YouTube links with key-moment markup."
